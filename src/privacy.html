B站视频总结助手

隐私政策

更新日期：2026 年 8 月 18 日

处理的数据

扩展会读取当前 B 站视频的公开字幕、标题、视频标识和页面地址。用户使用提问功能时，扩展还会处理用户输入的问题、选中的引用文字和问答记录。

数据用途与传输

上述视频内容和用户输入仅用于生成视频总结和回答问题。数据传输选项默认开启，用户可以随时关闭；仅在该选项开启时，这些内容才会直接发送到用户在设置中配置的 OpenAI 兼容 LLM API。服务提供方对数据的处理受其自身隐私政策约束。

本地与同步存储

API Key 仅保存在当前浏览器的 Chrome 本地存储中；Base URL、模型名称及普通界面设置保存在 Chrome 同步存储中。总结、时间线、亮点和问答历史保存在 Chrome 本地存储中。数据不会上传到扩展开发者控制的服务器。

共享与出售

开发者不会接收、出售或用于广告目的处理用户数据，也不会允许人工读取这些数据。数据只会在提供用户主动请求的总结和问答功能所必需时传输给用户选择的模型服务。

删除与控制

用户可以在历史记录中删除单条或批量删除本地总结，也可以通过 Chrome 的扩展数据管理功能清除全部数据。关闭“允许发送给所配置的 LLM 服务”后，扩展不会发起新的模型请求。

权限说明

扩展仅固定访问 B 站字幕资源和默认 DeepSeek API。使用其他 Base URL 时，会在用户保存设置时单独请求该服务域名的访问权限；切换服务后会移除旧服务域名权限。

Chrome Web Store Limited Use

本扩展对从 Chrome 获得的信息的使用遵守 Chrome Web Store 用户数据政策，包括 Limited Use 要求。
